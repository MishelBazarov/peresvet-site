# Сайт ЦТБИ «Пересвет», Армавир

Многостраничный сайт центра традиционных боевых искусств «Пересвет».
Собран на [Astro](https://astro.build): на выходе обычные HTML-страницы, которые кладутся на любой хостинг.

## Как запустить у себя

```bash
npm install
npm run dev      # сайт на http://localhost:4321
npm run build    # готовые страницы в папке dist/
```

Нужен Node.js 22.22 или новее.

### Добавить новость о турнире

Создать файл `src/content/novosti/2026-11-nazvanie.md`:

```md
---
title: Медали на первенстве края
date: 2026-11-20
type: rezultaty        # turnir — анонс, rezultaty — результаты, sobytie — событие
place: Краснодар
summary: Одна-две строки для карточки в списке.
medals:
  - name: Имя Фамилия
    place: 1
    category: 12–13 лет, 45 кг
---

Текст новости.
```

### Добавить бойца

Файл `src/content/boytsy/imya-familiya.md`, поле `coach: bazarov` (имя файла тренера) — боец появится в «Воспитанниках» на странице тренера.

## Как устроен сайт

- **Стиль.** «Знамя» (синий флага, золото, антиква) — главная, клуб, страница Т. Б. Базарова. «Арена» (почти чёрный, узкий спортивный шрифт) — новости, бойцы, результаты.
- **Плавность.** Прокрутка — Lenis, анимации — GSAP, переходы между страницами — встроенные View Transitions браузера. При включённом «уменьшении движения» анимации отключаются.
- **Всплывающая заявка.** Через 12 секунд на сайте (время считается по всем страницам). Не показывается на странице записи и в документах, после закрытия молчит 3 дня, после отправки больше не появляется. На телефоне выезжает снизу.
- **Заявки.** Форма отправляет данные на `public/api/lead.php`: заявка сохраняется на сервере в России (152-ФЗ), приходит на почту, в Telegram уходит только сигнал без личных данных. Настройки — `public/api/config.php` по образцу `config.example.php` (в репозиторий не попадает). В режиме `npm run dev` PHP не работает, поэтому форма покажет ошибку — это нормально.
- **Шрифты** лежат на нашем сервере (без запросов к Google).
